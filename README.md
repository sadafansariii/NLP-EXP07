# 🧠 Word Sense Disambiguation using LSTM/GRU

## 📌 Project Overview

Word Sense Disambiguation (WSD) is a Natural Language Processing (NLP) task that identifies the correct meaning of an ambiguous word based on its surrounding context. This project implements Word Sense Disambiguation using Bidirectional LSTM and GRU models with an Attention Mechanism in PyTorch.

The application processes input sentences, predicts the appropriate meaning of ambiguous words, and displays prediction confidence, sense probabilities, and attention scores.

## 🚀 Key Features

1. Text Tokenization and Vocabulary Generation  
2. Dataset Preparation for Ambiguous Words  
3. Bidirectional LSTM-based Word Sense Disambiguation  
4. Bidirectional GRU-based Word Sense Disambiguation  
5. Attention Mechanism for Context Representation  
6. Training Loss and Accuracy Evaluation  
7. Context-Based Word Sense Prediction  
8. Prediction Confidence and Sense Probabilities  
9. Attention Scores for Understanding Contextual Importance  
10. Test Cases for Ambiguous Words

## 🏷️ Word Sense Disambiguation Models

### Bidirectional LSTM

The Bidirectional Long Short-Term Memory (LSTM) model processes the input sequence in both forward and backward directions. It captures contextual information from both sides of an ambiguous word to help identify its intended meaning.

### Bidirectional GRU

The Bidirectional Gated Recurrent Unit (GRU) model also processes the sequence in both directions. It uses update and reset gates to learn contextual information and predict the appropriate word sense.

### Attention Mechanism

The Attention Mechanism assigns weights to the contextual representations generated by the recurrent model. It helps the model focus on relevant words when determining the meaning of an ambiguous word.

## 📚 Dataset

The project uses a small, manually prepared dataset containing **42 example sentences** involving four ambiguous words:

- **Bank** – Financial institution or riverbank
- **Bark** – Sound made by a dog or outer covering of a tree
- **Bat** – Flying mammal or sports equipment
- **Light** – Illumination or something with low weight

The dataset is used to train and test the models for contextual word sense prediction.

## 🔍 Word Sense Prediction

For a given input sentence, the application:

1. Tokenizes the sentence into words.
2. Converts the tokens into numerical representations.
3. Processes the sequence using the selected recurrent model.
4. Applies attention to generate a contextual representation.
5. Predicts the appropriate meaning of the ambiguous word.
6. Displays the predicted sense, confidence score, sense probabilities, and attention scores.
